# 🎒 Задача о рюкзаке (Knapsack Problem)

Консольная программа на Python, которая решает задачу о рюкзаке 0/1
четырьмя разными алгоритмами и позволяет сравнить их по результату и скорости.

## Что такое задача о рюкзаке

Есть рюкзак ограниченной **вместимости** и набор предметов. У каждого предмета
есть **вес** и **ценность**. Нужно выбрать предметы так, чтобы их суммарный вес
не превысил вместимость, а суммарная ценность была максимальной.

В варианте **0/1** каждый предмет можно либо взять целиком, либо не брать.

**Пример.** Вместимость 50, предметы: (вес 10, ценность 60), (20, 100), (30, 120).
Лучший выбор — второй и третий предметы: вес 50, ценность 220.

## Возможности

- Ввод предметов вручную или генерация случайных (до 1000 штук)
- Четыре алгоритма на выбор
- Режим «Сравнить все»: результат и время работы в одной таблице
- Понятный вывод: таблица выбранных предметов и полоса заполнения рюкзака
- Защита от неверного ввода: программа не падает, а просит повторить
- Только стандартная библиотека Python, ничего устанавливать не нужно

## Быстрый старт

Требуется Python 3.8 или новее.

```bash
python main.py
```

## Как пользоваться

1. **Добавьте предметы** — пункт 1 (вручную) или 2 (случайные).
2. **Задайте вместимость** — пункт 4. Если забыли, программа спросит сама.
3. **Решите** — пункт 5, затем выберите алгоритм или «Сравнить все».

Предмет вводится одной строкой: `название вес ценность`.
Название может состоять из нескольких слов, вес и ценность — целые числа,
вес больше нуля. Пустая строка завершает ввод.

```
Предмет 1: Палатка 12 40
Предмет 2: Спальник 8 30
Предмет 3: Еда 10 50
Предмет 4:
```

### Пример результата

```
── Динамическое программирование (0.03 мс) ──
  Название    Вес  Ценность
  Палатка      12        40
  Еда          10        50
  Аптечка       3        25

  Рюкзак: [████████████████████] 25 из 25
  Общая ценность: 115
```

### Пример сравнения алгоритмов

```
  Алгоритм                        Ценность   Вес   Время, мс
  ──────────────────────────────────────────────────────────
  Динамическое программирование        115    25        0.02
  Ветви и границы                      115    25        0.02
  Полный перебор                       115    25        0.02
  Жадный алгоритм                      110    22        0.00
```

Жадный алгоритм здесь дал 110 вместо 115 — он быстрый, но не всегда находит
оптимум.

## Алгоритмы

| Алгоритм                      | Точный? | Сложность          | Когда использовать                          |
|-------------------------------|---------|--------------------|---------------------------------------------|
| Динамическое программирование | да      | O(n · W)           | основной выбор при небольшой вместимости    |
| Ветви и границы               | да      | в худшем O(2ⁿ)     | большие веса, когда ДП-таблица слишком велика |
| Полный перебор                | да      | O(2ⁿ)              | эталон для проверки, до 20 предметов        |
| Жадный                        | нет     | O(n log n)         | нужен мгновенный приближённый ответ         |

Здесь `n` — число предметов, `W` — вместимость рюкзака.

**Динамическое программирование.** Строится таблица: лучшая ценность для первых
`i` предметов при вместимости `c`. По таблице восстанавливается набор предметов.

**Ветви и границы.** Перебор «взять / не взять» с отсечением. Для каждой ветки
считается оптимистичная оценка (как если бы предметы можно было делить); если
даже она не лучше найденного рекорда, ветка отбрасывается.

**Полный перебор.** Проверяет все подмножества предметов. Работает только
при небольшом их числе, зато наглядно и надёжно.

**Жадный алгоритм.** Сортирует предметы по ценности на единицу веса и берёт
подряд всё, что помещается. Может ошибаться, потому что не «заглядывает вперёд».

## Структура проекта

```
knapsack_project/
├── main.py              # точка входа и главное меню
├── algorithms.py        # алгоритмы решения
├── interface.py         # ввод данных и вывод результатов
├── test_algorithms.py   # проверка алгоритмов
├── README.md
└── .gitignore
```

| Файл                 | Назначение                                                      |
|----------------------|-----------------------------------------------------------------|
| `main.py`            | запускает меню и связывает ввод, алгоритмы и вывод              |
| `algorithms.py`      | функции `dp`, `bnb`, `brute`, `greedy` и словарь `ALGORITHMS`   |
| `interface.py`       | функции ввода с проверкой и форматированного вывода             |
| `test_algorithms.py` | автоматические проверки корректности алгоритмов                 |

## Тесты

```bash
python test_algorithms.py
```

Проверяется, что:
- на классическом примере ответ равен 220;
- жадный алгоритм ошибается на «ловушке», а точные — нет;
- пустой список предметов и нулевая вместимость обрабатываются корректно;
- на 200 случайных наборах динамическое программирование и ветви и границы
  дают ту же ценность, что и полный перебор, и не превышают вместимость.

## Как добавить свой алгоритм

1. Напишите в `algorithms.py` функцию, которая принимает `(items, cap)` и
   возвращает список выбранных предметов (кортежей `(название, вес, ценность)`).
2. Добавьте её в словарь `ALGORITHMS` с новым номером, названием и пояснением.
3. Если номер больше 4, поправьте диапазон выбора в `solve()` из `main.py`.
4. Добавьте проверку в `test_algorithms.py`.

## Ограничения

- Вес и вместимость — целые числа (иначе таблица динамического программирования
  невозможна).
- Полный перебор отключается при числе предметов больше 20.
- Динамическое программирование хранит таблицу `n × W`, поэтому при очень
  большой вместимости потребует много памяти — используйте ветви и границы.
